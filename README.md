# 26_Digital_Inclusion

Projeto de inclusão digital com foco em informática básica, ferramentas de produtividade, autonomia tecnológica e desenvolvimento de habilidades para a vida, estudos e trabalho.

## Sobre o projeto

Este repositório reúne materiais, atividades, registros pedagógicos sanitizados e recursos públicos de um ciclo de formação em inclusão digital.

O projeto parte de uma experiência pedagógica acumulada e utiliza o diagnóstico da nova turma para adaptar o percurso de aprendizagem.

**Princípio central:** não começar do zero, não repetir automaticamente, aprender com o que já foi vivido e adaptar o caminho à realidade da nova turma.

## Percurso atual

O ciclo será desenvolvido em **12 aulas**, com planejamento ajustável conforme conhecimento prévio, participação, dificuldades, velocidade de aprendizagem, autonomia e evolução.

A sequência das aulas não é tratada como uma lista rígida de conteúdos. O aprendizado observado orienta os próximos passos.

## Para os alunos

O futuro GitHub Pages será utilizado como portal público para acesso a:

- aulas;
- materiais de apoio;
- exercícios;
- modelos;
- atividades práticas;
- projetos;
- orientações e recursos complementares.

## Princípios pedagógicos

**Tecnologia → Aprendizagem → Autonomia → Inclusão → Participação social → Empregabilidade**

Sempre que possível:

**Ferramenta → Tarefa → Finalidade → Situação real**

## Histórico pedagógico

O projeto dá continuidade a experiências anteriores de formação em informática. Essas experiências são utilizadas como referência para identificar estratégias que funcionaram, dificuldades recorrentes e possibilidades de melhoria.

A nova turma, entretanto, será diagnosticada individual e coletivamente. O histórico não determina o planejamento.

## Privacidade e dados sanitizados

Este projeto foi concebido para publicação pública. **Nenhum dado pessoal identificável de alunos deve ser publicado neste repositório ou no GitHub Pages.**

Não publicar nomes, contatos, documentos pessoais, notas individuais, frequência individual identificável, diagnósticos pessoais, informações socioeconômicas individuais ou fotos identificáveis sem autorização adequada.

Registros públicos devem utilizar somente informações agregadas, anonimizadas ou sanitizadas.
