# Portfólio de aprendizagem

Ao longo do ciclo, o aluno poderá reunir produções que demonstrem sua evolução.

## Possíveis evidências

- documento de texto;
- apresentação;
- planilha;
- currículo ou documento para trabalho;
- atividade prática;
- projeto final.

## O que o portfólio mostra

O foco não é apenas terminar arquivos. É observar a progressão:

**com ajuda → com orientação → com pouca ajuda → sozinho → aplicando em outra situação**.

O portfólio público não deve conter dados pessoais desnecessários. Arquivos individuais só devem ser publicados quando houver autorização adequada e quando a exposição for apropriada.
