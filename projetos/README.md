# Projetos

Espaço para atividades integradoras desenvolvidas durante o ciclo.

Os projetos devem partir de situações reais e permitir que o aluno combine diferentes habilidades digitais.

Exemplos de possibilidades:

- documento pessoal;
- apresentação temática;
- planilha simples;
- organização de informações;
- atividade final integradora.

O projeto concreto será definido conforme o percurso da turma.
