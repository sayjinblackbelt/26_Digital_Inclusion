# Missões e desafios

As missões transformam cada conteúdo em uma tarefa concreta.

## Princípio

Não existe ranking entre alunos. A referência principal é a própria evolução.

## Progressão

### 🟢 Missão
Realizar uma tarefa com orientação.

### 🔵 Desafio
Repetir a tarefa com menos ajuda.

### 🟣 Autonomia
Aplicar o que foi aprendido em uma situação nova.

## Exemplos

- Encontrar e abrir um programa.
- Criar e localizar um arquivo.
- Organizar uma pasta.
- Pesquisar uma informação.
- Produzir um documento.
- Criar uma apresentação.
- Montar uma pequena tabela.
- Resolver uma situação digital do cotidiano.

As missões específicas serão liberadas conforme o desenvolvimento da turma.
