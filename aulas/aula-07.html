Aula 07

Apresentações digitais

Entender como organizar uma apresentação para comunicar uma ideia.

Curso / Aula 07

Objetivo

Conhecer a lógica de uma apresentação: tema, sequência, informação principal e leitura visual.

Prática possível

  1. definir um tema;
  2. criar título;
  3. separar ideias;
  4. organizar slides;
  5. apresentar o resultado.

Foco

Comunicar com clareza é mais importante do que usar muitos efeitos ou recursos.
