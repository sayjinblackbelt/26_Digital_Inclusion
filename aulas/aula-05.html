Aula 05

Documentos práticos

Usar um editor de texto para criar algo que tenha finalidade real.

Curso / Aula 05

Objetivo

Produzir um documento curto, compreendendo a relação entre ferramenta, tarefa, finalidade e situação real.

Exemplos

  • aviso;
  • lista organizada;
  • pequeno texto;
  • modelo simples de currículo;
  • outro documento útil para a turma.

Foco

Mais importante que memorizar comandos é compreender para que cada recurso serve e conseguir repetir o processo depois.

Ferramentas

Word, Writer e Google Docs. Compare os recursos sem transformar uma ferramenta específica em requisito.

Situação real

Criar um documento que possa ser realmente usado: currículo simples, comunicado, declaração, lista organizada ou texto de apresentação.
