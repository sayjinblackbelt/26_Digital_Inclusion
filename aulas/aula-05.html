Aula 05

Documentos profissionais

Usar um editor de texto para produzir algo que tenha finalidade real.

Curso / Aula 05

Objetivo profissional

Criar um documento curto e funcional, escolhendo recursos de acordo com a tarefa.

Escolha uma entrega

Currículo simples, comunicado, lista organizada, declaração, texto de apresentação ou outro documento útil.

Ferramentas

Word, Writer ou Google Docs. A competência deve ser transferível entre ferramentas.

Critério

O leitor consegue entender rapidamente o que o documento comunica?

Missão · documento com finalidade

Escolha uma situação real e produza uma primeira versão. Depois, revise título, ordem das informações, clareza e localização do arquivo.
