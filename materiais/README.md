# Materiais

Este diretório concentra materiais públicos de apoio ao ciclo.

## Organização

- `guias/` — orientações rápidas para alunos;
- `exercicios/` — práticas e desafios;
- `modelos/` — modelos que podem ser adaptados para situações reais.

Novos materiais entram conforme a necessidade da turma. O portal prioriza recursos curtos, claros e reutilizáveis.
