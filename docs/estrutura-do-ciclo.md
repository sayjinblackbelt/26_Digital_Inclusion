# Estrutura do ciclo de 12 aulas

## Como interpretar este planejamento

As 12 aulas formam o horizonte do ciclo, não um roteiro rígido.

A primeira aula tem função diagnóstica. A partir dela, o percurso pode mudar de ordem, ganhar reforços ou avançar mais rapidamente.

## Percurso inicial de referência

| Aula | Foco inicial | Status |
|---|---|---|
| 01 | Apresentação, exploração e diagnóstico | Preparada |
| 02 | Fundamentos digitais identificados no diagnóstico | Ajustar após Aula 01 |
| 03 | Organização do computador e arquivos | Hipótese de percurso |
| 04 | Digitação e produção de texto | Hipótese de percurso |
| 05 | Editor de texto: documentos práticos | Hipótese de percurso |
| 06 | Formatação e produção orientada | Hipótese de percurso |
| 07 | Apresentações digitais | Hipótese de percurso |
| 08 | Produção de uma apresentação | Hipótese de percurso |
| 09 | Planilhas e organização de dados | Hipótese de percurso |
| 10 | Cálculos, funções simples e leitura de dados | Hipótese de percurso |
| 11 | Aplicação prática para vida e trabalho | Hipótese de percurso |
| 12 | Projeto, revisão, autonomia e percepção de evolução | Hipótese de percurso |

## Regra de adaptação

Após cada encontro:

**Planejar → Ensinar → Observar → Registrar → Analisar → Ajustar**

Uma etapa pode ser repetida, dividida ou antecipada quando a turma precisar.

## Critério de avanço

O conteúdo seguinte deve entrar quando houver evidência suficiente de que a turma consegue usar o conhecimento anterior, com o nível de ajuda adequado.

## Evidências observadas

- execução da tarefa;
- compreensão do procedimento;
- repetição sem dependência excessiva;
- adaptação a uma situação semelhante;
- aplicação em situação nova;
- capacidade de explicar o que fez.
